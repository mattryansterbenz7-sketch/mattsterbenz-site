How a single opportunity gets enriched

You bring the company. Coop brings the rest.

Drop into a job posting or company site. By the time you've read the page, Coop has already pulled what your inbox, calendar, and meeting notes know about them — and scored the fit.

The integrations, plain-English

Six places Coop reads from. Zero places it sends anything to.

Coop's default brain is your Claude Desktop, plugged in via MCP — no API keys to set up. The data integrations pull your inbox, calendar, and meeting notes straight into Coop's browser-local store. Every byte stays in your browser.

The trigger
In-page detection
Built in · no setup

A content script reads LinkedIn, Greenhouse, Lever, Workday, and Ashby pages directly. The moment you open a job posting or company page, Coop pulls the title, JD, comp band, and requirements. No clicks. No paste.

Web research (Serper)
Optional · BYO key for auto-fire

Skip the key and ask Claude Desktop to research a company — it'll call Coop's MCP and pull firmographics, leadership, reviews, and recent news on demand. Add a Serper key to let Coop fire the same research automatically in the background. Cached indefinitely; force-refresh from the side panel.

Your communication history
Gmail
Chrome OAuth

Reads threads where the sender or recipient domain matches the company. Surfaces who you've corresponded with, flags rejection language, and feeds the "last activity" + "Action on" signals on every kanban card.

Google Calendar
Chrome OAuth

Lists events whose attendees include the company's email domain. Powers "next meeting," the upcoming-events sidebar, and the relationship timeline. Past meetings backfill your history with the company automatically.

Granola
REST API key

Searches your meeting notes by company name and contact name. Pulls the transcript paragraph that mentions them — verbatim, in their own words. Indexed once with rate-limited backoff, then queried per opportunity.

The brain · Claude Desktop by default
Claude Desktop (MCP)
Default · no key needed

Coop registers as an MCP connector in your Claude Desktop app. Ask Claude anything about an opportunity — score it, draft an outreach note, debrief a call — and it calls Coop in the background to assemble the context. Zero API keys to get started. Same Claude you already pay for.

Anthropic API key (opt-in)
Optional · unlocks auto-fire

Add an Anthropic key to unlock background work that fires without opening Claude Desktop — fresh-data sweeps, queue auto-scoring, scheduled drafts. Same Claude under the hood; just the auto-fire path instead of the on-demand one.

OpenAI (opt-in)
Optional · alt provider

Prefer GPT over Claude for the auto-fire path? Bring an OpenAI key and Coop routes background work through it instead. If you configure both providers, Coop cycles between them on rate-limits and the UI tells you which model answered.
