API reference

Install the script, identify your visitors, and listen for conversation events.

Installation

Add the snippet to every page you want covered, ideally in your base template.

<script src="https://cdn.rep.ai/v1/widget.js"
        data-workspace="YOUR_WORKSPACE_ID" async></script>

Identifying a visitor

If you already know who the visitor is, pass it along so the agent can skip the introductions and the enrichment lookup.

Rep.identify({
  email: "dana@northwind.com",
  company: "Northwind Logistics",
  plan: "enterprise"
});

Conversation events

Subscribe to lifecycle events to mirror activity into your own systems.

Rep.on("conversation.qualified", (payload) => {
  analytics.track("Lead Qualified", payload);
});

Rate limits

Identify calls are limited to 60/minute per workspace. Event subscriptions are unmetered.
